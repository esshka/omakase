# Commit subjects

- One line, under 50 characters, no trailing period.
- Say what the change means for someone using the library, not which files moved.
- Present tense, no `feat:`/`fix:` prefixes, no ticket numbers.
- Prefer a plain sentence to a noun phrase: `Make it safe to run in Rails`, not `Rails safety`.
